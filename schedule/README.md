# Запуск по расписанию

Команда одна и та же — `uv run prime replay`. Планировщик просто вызывает её раз в минуту
(для демонстрации) или раз в сутки (в жизни). Каждый запуск берёт следующий день учебного
времени; пропущенный запуск день не теряет.

| Система | Чем | Файл |
|---|---|---|
| macOS, Linux | cron | [`crontab.txt`](crontab.txt) |
| macOS | launchd | [`prime-replay.plist`](prime-replay.plist) |
| Windows | Планировщик заданий | команда ниже |

## Windows: Планировщик заданий

В PowerShell, подставив свой путь к проекту:

```powershell
schtasks /Create /TN prime-replay /SC MINUTE /MO 1 /TR "cmd /c cd /d C:\work\prime-l9-workshop && %USERPROFILE%\.local\bin\uv.exe run prime replay >> logs\task.log 2>&1"
```

Проверить, что задача есть: `schtasks /Query /TN prime-replay`. Удалить: `schtasks /Delete /TN prime-replay /F`.
То же самое мышкой: «Планировщик заданий» → «Создать простую задачу».

## Что проверить после включения

1. Через пару минут в `logs/prime.log` появились строки `replay: … обработан` — по одной в минуту.
2. В `state/replay.json` дата отчёта растёт.
3. Если строк нет — смотрите `logs/cron.log` (или `launchd.log`, `task.log`): туда попадает всё,
   что упало до того, как программа успела открыть свой журнал. Чаще всего это «uv: command not found».

## Не забудьте выключить

Учебный снимок кончается 30 августа 2026: после этого `replay` пишет в журнал предупреждение
и ничего не делает. Но планировщик продолжит будить его каждую минуту, пока вы его не выключите.
